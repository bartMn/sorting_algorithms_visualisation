# Sorting Algorithms Visualization

This project provides a graphical visualization of various sorting algorithms. Users can select a sorting algorithm, shuffle the data, and observe the sorting process in real-time.

## Features

- Visualize popular sorting algorithms:
  - Selection Sort
  - Bubble Sort
  - Cocktail Shaker Sort
  - Insertion Sort
  - Shellsort
  - Merge Sort
  - LSD Radix Sort
  - Quick Sort
- Real-time updates of the number of comparisons and swaps.
- Interactive GUI built with `Tkinter`.

## How to Run

1. Ensure all files are in the same directory.
2. Run the `runner.py` file:
   ```bash
   python runner.py

3. A window will pop up where you can:
   Select a sorting algorithm from the dropdown menu.
   Click "Shuffle" to randomize the data.
   Click "Sort" to visualize the sorting process.

### Requirements
Python 3.x
Tkinter
